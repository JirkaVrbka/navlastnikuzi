# Design Proposals

Write a short proposal before: a new module, a cross-cutting change, a schema/API change, or an infra change.
For this project, write one before the **delay-propagation** logic and the **voting/elimination** flow — both
have edge cases worth settling on paper first.

## Format
- **Problem statement**
- **Proposed solution** (with a Mermaid diagram where it helps)
- **Alternatives considered**
- **Impact assessment** (perf, security, migration, blast radius)
- **Open questions**
- **Acceptance criteria**
