# NaVlastníKůži

A web app that helps the **organizers** of a _Traitors_-style LARP (live-action role-play) game run
their event. It replaces the usual mix of spreadsheets, paper notes, and group chats with one shared
screen that everyone on the organizing team can see and update during the night.

The app is in **Czech** and is used **only by organizers** — players don't have accounts or access to it.

## What it does

- **Itinerary** — the plan for the event, broken into days and timed events (start/end time, place,
  who's running it, a checklist, and notes). When something runs late, an organizer applies a **delay**
  and every later event that day shifts automatically, so the schedule always shows realistic times.

- **Players overview** — a roster of everyone playing: photo, name, nickname, notes, and current status.
  When a player is out of the game, the app records why (murdered by the traitors or voted out) and keeps
  track of the order in which people dropped out.

- **Voting tracker** — run the group's votes in real time. Add or remove a vote for each player with a
  tap, sort the list, and when the round ends pick who's eliminated. Finished votes are archived so the
  team always has the full history of the night.

## Who it's for

A small, trusted group of event organizers who are all running the same game at the same time. One admin
can add the other organizers; there is no public sign-up and nothing is player-facing.

## Status

Prototype / MVP — an in-progress tool built for real game nights.
